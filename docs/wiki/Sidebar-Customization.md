# Sidebar Customization

The left navigation is locked during normal use.

Choose the small **cog** to enter sidebar edit mode.

While editing:

- double-click a section name or press **F2** to rename it
- drag only from the three-line grip at the right side of a row
- drop between rows to choose the new position

Names and order save automatically.

Turn the cog off to return to ordinary navigation. Edit hints and drag grips are hidden when edit mode is disabled.

Sidebar preferences are stored separately from financial data.
